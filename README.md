## Sales Performance Dashboard

## Overview
An interactive Excel dashboard analyzing sales performance, revenue, and profit across regions, product categories, and sales representatives.


## Files
* **Sales Performance.Dashboard.xlsx**: Contains the interactive visual dashboard layout (while the dataset and pivot tables are maintained together in a separate workbook file hosted in the Sales-Performance-Dataset repository).


## Key Insights
1. **Laptop A13** is the most profitable product, generating 22.62% of total profit.
2. **Peter** is the top-performing sales representative with 435M in total revenue.
3. **Lagos** leads regional COGS with 494M.
